# 用量、价格与预算

FolioCross 为每次模型请求记录实际模型、阶段、章节、尝试次数、输入 token、输出 token、
缓存命中 token 和费用。界面可按阶段、模型、章节及最近请求查看；失败尝试单独保留，避免
把重试消耗藏在总数中。

价格字段属于模型配置，并带币种、生效日期和来源。默认 `deepseek-v4-flash` 使用 DeepSeek
自 2026-08-16 生效的官方美元价格：谷时缓存命中输入 0.007 美元、未缓存输入 0.22 美元、
输出 0.66 美元（每百万 token）；工作日 UTC 01:00–04:00 和 06:00–10:00 为峰时，
单价为谷时两倍。设置页面可以修改这些基础价格。价格未知时只显示 token，不猜测金额。

官方来源：https://api-docs.deepseek.com/quick_start/pricing/

软预算在创建下一次模型请求前检查，达到提醒值后记录一次警告但继续运行。硬预算同样在
创建下一次模型请求前检查，达到上限后任务转为安全暂停；已经发出的在途请求无法撤回。
默认“稳妥加速”不执行全文润色或深度审校，深度审校必须由用户主动启动。
切换到 OpenAI、Ollama 或 vLLM 时会清除 DeepSeek 专属单价、峰谷时段和价格来源；用户没有
填写对应服务价格时只统计 token，不把 DeepSeek 单价误套到其他模型。显式 TPM 小于单次请求
估算时会允许该请求独占当前时间窗，避免任务永久等待；后续请求仍会等待新的 60 秒窗口。
