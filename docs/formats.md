# 格式兼容

## EPUB

导入时读取 OPF manifest 和 spine，以 XHTML 物理资源和块序号建立稳定定位。行内标签、图片、
普通链接及脚注链接会转换成受保护标记，翻译后恢复原 HTML。导出复制原 EPUB 包，只替换正文
块和语言元数据，因此 CSS、图片、封面及未处理资源保持不变；目录和正文 `<title>` 会根据
对应章节标题译文同步更新。导出前会重新核对资源、块序号和原文，定位失效时明确停止，不能
静默漏掉段落。脚注链接指向 spine 之外的独立 XHTML 时，也会只追加读取实际被引用的脚注资源。
超过阈值的带格式段落会在不切断内部标记的前提下拆分，所有片段仍能逐字重组回原模板。

## MOBI/AZW

MOBI、AZW/AZW3/AZW4、PRC 等格式首先调用独立安装的 KindleUnpack 环境，将无 DRM 的
Mobi7/KF8 内容规范化为 EPUB；失败后才尝试外部 Calibre `ebook-convert`。因此 Calibre 不是
硬依赖。转换结果按原文件 SHA-256 缓存。FolioCross 不移除 DRM；受保护文件会明确失败。

## DOCX

正文段落、标题、列表和表格单元格会按 `word/document.xml` 中的真实顺序进入翻译。导出直接
复制原 OOXML 包，只改正文文本节点并按原 run 比例分配译文，不再用文档库重新生成整个文件；
图片、样式、编号、关系和未知扩展部件保持原字节。文本框和修订记录会在导入警告中明确说明。

## 其他格式

FB2、HTML、TXT 和 Markdown 会转换成统一章节模型。嵌套 FB2 章节、嵌套列表和引用块会按各自
正文层级提取，不会重复或漏掉父级文字。它们可以输出为 EPUB、DOCX、HTML、TXT 或 Markdown；
跨格式纯文本输出会移除内部格式标记，不会把 `⟦FC:...⟧` 暴露给读者。首版不支持 PDF 和 SRT。
